# G2 — Cottage and warehouse hero architecture (first source pass, 30 October 2026)

The owner provisionally approved G1 as a buildable landform baseline and authorised G2. This is a first implemented G2 source iteration, not the full gate.

The typed GDScript module HMHeroBuildingArtG2 creates faceted batched and muted/weathered 1B timber/iron detail attached strictly inside original HMInspectTarget owners. Cottage front infill owns the gable posts/rakes, door jambs, lintel and iron pinning; cottage roof beam owns collar/joist geometry. Each original/expanded warehouse back-frame bay owns raked timber braces and fasteners; existing roof course parts own underside rafters/battens. There are no extra colliders, extra part IDs, outputs, upgrades, story changes, automatic work systems or balance changes. All art vanishes with the saved parent part's release.

Godot regression test test_g2_hero_architecture.gd verifies all 345 original live salvage targets remain, G2 facets are part-owned, the nine-cottage-part manual-user transaction suite including progressive release runs through original support rules, and a real disk save/reload does not resurrect removed owned G2 visuals.

**G2 not yet complete:** Blender-editable .blend and exported GLB assets are still required for approved final artist assets, full warehouse manually ordered teardown, rendered intact/partial/near-empty **real transaction** comparisons, and human first-person carrying test. Original generic existing decor remains and must be replaced/refined in a later G2 pass, not expanded across G3 prematurely.

## Cottage production model, texture and assembly milestone — verified 30 October 2026

The user directed G2 in the exact sequence **individual reusable models → muted stylised materials → physically dismantlable cottage**. All three steps are now implemented as real source/game assets. This does not close the entire cottage+warehouse G2 art acceptance gate.

**Authoring & editable sources**
- `tools/generate_g2_cottage_assets.py`: deterministic source for 10 independent reusable component GLBs and nine independently salvage-owned cottage assembly GLBs; produces 16 PBR texture PNGs across 8 material types and `art/g2/cottage_model_manifest.json` with per-file SHA256 and counts.
- `tools/create_g2_cottage_blend.py`: reimports these actual source GLBs, groups meshes by original salvage owner and writes the real editable Blender 4.0 source `art/g2/source/Hollowmere_Cottage_G2_Master.blend`. Blender 3.12 system NumPy was required on the Linux QA runner. Blender backup versions are disabled; no duplicate .blend1 is retained in current branch.
- Nine game-owner assets: `game/assets/models/g2/cottage/part_{curtain,shutters,cladding,slate_patch,beam,stone_block,front_infill,rear_infill,threshold}.glb`. Each is directly owned by its original `fixture/house/*` HMInspectTarget. Cottage part kit includes posts, crossbeams, knee braces, weatherboards, lime panel, rough stone, overlapping slate, shutter leaf, cloth curtain, iron strap.
- Material source set in `game/assets/materials/g2/`: weathered oak, dark oak, lime infill, fieldstone, slate, black iron, unbleached linen and packed earth. Each has a 256 px albedo PNG and packed ORM PNG. Each GLB embeds its own texture images for portability. Weathering is restrained 1B Balanced Facets with selective 1C detail, no blue-painted plaster.
- GDScript production assembly in `game/scripts/buildings/hm_building_prefab.gd`: for `working/cottage_01` it constructs the canonical nine targets and their authoritative colliders from existing manifest first, then replaces only the provisional visuals with the corresponding importable GLB instances. No changes to tool requirements, support graph, yields, save IDs, player animation or passive harvesting. `HMHeroBuildingArtG2` automatically skips duplicate cottage-only visual add-ons, preserving the warehouse pass.
- Physical slate sarking beneath all overlapping roof tiles was added after direct visual review exposed gaps to the sky. It belongs to the existing roof owner and disappears on normal manual release.
